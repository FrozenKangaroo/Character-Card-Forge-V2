# v0.20.1 Discoverability and Power-User Workflow

v0.20.1 adds faster ways to begin, find and switch workflows without changing the
underlying character data or duplicating existing tools.

## New Project

Every New Project entry point now opens the same creation-method chooser. Choose a
starting template and creation method, then press **Create Project** (or double-click
the method) to continue in Blank Workspace, Manual Guided, Idea Generator,
Character Collaborator, Idea Notebook, Import, or a clean Template Start. The chosen
route opens the existing tool after creating the ordinary editable project.

## Quick Actions and shortcuts

Open **Quick Actions** from the sidebar or press **Ctrl+K**. Type part of an action,
tool, layout, or shortcut and press Enter to run the first visible result.

- **Ctrl+N** — New Project
- **Ctrl+F** — Character Library search
- **Ctrl+S** — Save the current project
- **Alt+Up / Alt+Down** — Previous or next visible character field
- **Ctrl+Shift+R** — AI Review
- **Ctrl+Shift+D** — Compare and Improve
- **Ctrl+Shift+E** — Export or Install
- **Ctrl+Shift+L** — Lorebook Manager
- **F1** — Getting Started

On macOS, Command can be used in place of Ctrl.

## Workspace layouts

The Workspace Layout menu provides Editing, Review, Lorebook, Front Porch Deployment,
and Group Card presets. A preset selects or opens the existing surface needed for that
task. Detachable tools remain detachable and are not closed merely because the layout
changes.

## Getting Started

The first-run guide explains project creation, optional AI setup, Quick Actions, and
the Library. Closing it records the choice locally; **Getting Started** in the sidebar
or **F1** reopens it at any time.
