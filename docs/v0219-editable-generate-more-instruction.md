# v0.21.9 Editable Generate More Instructions

v0.21.9 lets an author steer each explicit **Generate More Ideas…** request without
changing the completed working batch or the main Idea Generator controls.

## Prompt or Additional Direction

The Generate More dialog now includes the requested Idea count and a comfortable
multiline instruction editor.

- A batch created without an Idea Source shows **Prompt**.
- A batch created from an Idea Source shows the frozen source title and labels the
  editor **Additional Direction**.
- The first extension is prefilled from the instruction used by the completed batch.
- After an extension successfully retains new Ideas, its confirmed instruction becomes
  the next prefill.
- The author may keep, tweak, replace or clear the text. Cancelling does not save an
  edited value.

With an Idea Source, clearing Additional Direction means “generate directly from this
frozen source.” CCF does not send a blank direction heading.

## Frozen creative context

The working batch owns a frozen copy of its Idea Source ID, title and prepared source
context, plus its Series context. Generate More never reads whichever source or prompt
happens to be active in the main Idea Generator UI. Only the per-extension Prompt or
Additional Direction changes.

Every provider sub-request in one manual extension—including its optional one-shot
shortfall replacement—uses the same confirmed instruction. Retained, unchecked,
validation-rejected and later-deleted concepts remain shared anti-repeat memory, so a
new setting or constraint does not reset repeat prevention.

## Extension-only Final Idea Review

When Final Idea Review is enabled for Generate More, the checklist contains only the
Ideas generated by that manual extension. Request-adherence findings are accepted only
for those new Ideas; older Ideas were generated under earlier instructions and are not
reclassified as mismatches.

Similarity review still compares new Ideas with one another and with retained older
Ideas. CCF keeps only similarity clusters containing at least one new extension Idea,
so already-reviewed old-versus-old relationships are not repeated. Applying the review
can reject only the displayed extension candidates; older retained Ideas remain kept.

## Failure and project safety

Typing in or cancelling the dialog does not mutate curation state. If an active manual
extension is cancelled or completes without a retained new Idea, CCF restores the
previous visible batch and previous successful prefill while retaining useful rejected
candidate memory. Project switching continues to discard unrelated curation state.
