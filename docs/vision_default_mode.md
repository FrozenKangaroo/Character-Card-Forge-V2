# Default Vision Analysis Contract

Default Vision Analysis is a conservative visual-reference workflow, not a miniature full character generator.

## Default mode

The default `concept` mode may propose:

- a visual-reference generation concept;
- the existing/current character name when available;
- visually observable tags;
- a physical Description.

The Description must remain character-focused and visual. It may include observable age range, build, face, skin, hair, eyes when visible, clothing, accessories, and distinguishing physical features.

The Description must not absorb pose/action, furniture, room/background, location, scenery, lighting, camera composition, personality, mood, history, occupation, relationships, motives, or other hidden/inferred facts.

Default mode does not propose Personality. Scene/environment observations may remain in the visual-reference concept when useful for later image-generation context.

## Full-card mode

The explicit `full_card` mode retains the broader review-first generation behaviour. Any non-visible personality, history, relationship, or roleplay material remains a creative proposal rather than a visual observation.
